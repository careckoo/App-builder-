How it works without typing

One Shortcuts automation, set up once

iOS doesn't let any app read your SMS inbox. Apple's supported route is a Shortcuts automation that you approve per sender. After that it runs by itself in the background.

1. Bank texts you

ADCB, FAB, Emirates NBD, ADIB, Liv, Wio and others send an alert for every card payment.

2. Automation runs

“When I get a message from ADCB → Run immediately → Sarfi: Log bank message.”

3. Sarfi updates

It reads amount, merchant, card and balance, picks a category, skips OTPs and duplicates, and refreshes the widget.
